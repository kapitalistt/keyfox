## 🦊 KeyFox v1.0.0

First public release of **KeyFox**, a smart, fast and secure password manager that lives in your terminal.

### Highlights

- 🔐 One encrypted vault file: **Argon2id** key derivation + **XChaCha20-Poly1305** encryption (libsodium)
- 🖥️ Full-screen animated TUI with mouse support and instant search
- 🔢 Built-in **2FA (TOTP)** codes
- 🎲 Password and passphrase **generator** with entropy and brute-force estimate
- 📋 Clipboard auto-clear, excluded from Win+V history and cloud sync
- ⏱️ Auto-lock with memory wiping
- 🌍 **English** (default) and **Russian** UI, switch with `F2`
- 📦 Single portable `keyfox.exe`, no installer, no DLLs, no telemetry, no cloud

### Quick start

1. Unzip and run `keyfox.exe` in **Windows Terminal** (window at least 96×28).
2. Create a vault and choose a strong master password. **It cannot be recovered.**
3. Press `F1` for help, `g` for the generator, `n` for a new entry.

### Notes

- The executable is **not code-signed**; Windows SmartScreen may show a warning. Verify the SHA-256 or [build from source](https://github.com/YOUR_USER/keyfox/blob/main/BUILD.md).
- The code has not been independently audited. Keep backups of your `.kfx` file.
